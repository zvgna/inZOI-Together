# inZOI Together

Мод в разработке для совместной игры в **inZOI** с двух компьютеров. Один игрок создаёт комнату и становится хостом, второй подключается как гость и выбирает другую семью.

## Текущее состояние

Мод предназначен для тестирования. В версии **0.5** подготовлены:

- Комнаты для хоста и гостя с кодом подключения.
- Передача выбранного сохранения с компьютера хоста на компьютер гостя.
- Автоматическая установка копии сохранения и выбор персонажа гостя.
- Экспериментальная синхронизация координат и переписка через игровой телефон.

Полный сценарий версии 0.5 на двух компьютерах ещё проверяется. Действия персонажей, время, предметы, деньги и отношения пока не синхронизируются. Перемещение может отображаться скачками.

В следующей тестовой сборке **0.6** добавлены проверка связи с хостом и экспериментальные запросы приветствия, рукопожатия и объятий. Доступность определяет игра; синхронное выполнение на двух ПК ещё требует проверки.

Для игры с другом из другого города см. [подготовку сети Radmin VPN / Hamachi](together/REMOTE-PLAY.md).

## Что понадобится

- Два компьютера с Windows и одинаковой версией inZOI.
- Одинаковая сборка мода на обоих компьютерах.
- Общая локальная сеть. Для подключения через интернет можно использовать Radmin VPN или Hamachi, но такую работу ещё нужно проверить.
- Запущенный помощник из комплекта мода на каждом компьютере.
- Включённый локальный MCP игры на порту `11212` для работы помощника.

Сохранение должно содержать как минимум две жилые семьи. Совместимость со сторонними модами пока не гарантируется.

## Установка

Используйте готовый тестовый ZIP-комплект. Этот репозиторий содержит исходники; скачивание через **Code → Download ZIP** не заменяет установочный комплект. Готовые сборки, когда они опубликованы, доступны в разделе [Releases](https://github.com/zvgna/inZOI-Together/releases).

1. Распакуйте комплект на обоих компьютерах.
2. Содержимое папки `mod` скопируйте в `Документы\inZOI\Mods\InGame`.
3. Проверьте, что файл мода находится по пути `InGame\InZOITogether_CFE6AC67\mod_manifest.json`.
4. Папку `helper` сохраните целиком в удобном месте. Запустите из неё `start-helper.cmd` и оставьте окно открытым.
5. Запустите игру и включите мод в управлении модами.

Отдельно устанавливать Node.js для готового комплекта не требуется.

## Создание комнаты

На компьютере хоста:

1. Сохраните текущую игру и выйдите в главное меню.
2. Нажмите **F2** и выберите **«Хост»**.
3. Нажмите **«Хост: выбрать сохранение»**, выберите файл из списка.
4. Нажмите **«Загрузить сохранение и создать комнату»**.
5. После загрузки снова откройте F2. Передайте гостю код комнаты и адрес из блока **Wi-Fi / LAN**.

Хост передаёт выбранное сохранение с диска. Несохранённые изменения в него не входят.

## Подключение гостя

На компьютере гостя:

1. Откройте главное меню игры, затем нажмите **F2**.
2. Выберите **«Гость»**, введите адрес хоста и код комнаты, нажмите **«Подключиться»**.
3. Выберите персонажа свободной семьи.
4. Нажмите **«Скачать сохранение и войти гостем»**.
5. Дождитесь загрузки и снова откройте F2 для завершения подключения.

Помощник устанавливает сохранение в отдельную папку. Существующие сохранения гостя не перезаписываются. Повторный вход создаёт новую копию; старые копии автоматически не удаляются.

Для проверки координат снимите игровую паузу на обоих компьютерах. Для переписки откройте телефон своего персонажа. Двусторонняя доставка сообщений в версии 0.5 ещё проверяется.

## Если не подключается

- Убедитесь, что помощник запущен на обоих компьютерах.
- На гостевом ПК укажите сетевой адрес хоста. Адрес `127.0.0.1` подходит только для подключения на самом компьютере хоста.
- Проверьте код комнаты: при создании новой комнаты он меняется.
- Разрешите серверу доступ к домашней сети в брандмауэре Windows.
- При сообщении о занятом месте нажмите **«Переподключить это место»**.
- Если помощник просит выйти в главное меню, сначала сохраните текущую игру.

## Сообщить о проблеме

Создайте обращение в [Issues](https://github.com/zvgna/inZOI-Together/issues). Укажите версии игры и мода, на каком компьютере возникла ошибка, и приложите снимок окна F2 с её текстом. Код комнаты и личные сохранения прикладывать не нужно.
