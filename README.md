# inZOI Together

Экспериментальный мод для кооперативной игры в **inZOI** по локальной сети. Цель — общий мир у хоста и управление разными семьями с двух ПК.

Текущий этап: **0.5 — комната «Хост / Гость» и перенос стартового сохранения**. Полноценная синхронизация игрового мира ещё не реализована.

## Возможности и статус

- Комната для двух участников с кодом подключения.
- Выбор сохранения хостом и подготовка отдельного снимка.
- Скачивание гостем по одноразовой ссылке, проверка SHA-256 и распаковка в новую папку SaveGames.
- Запрос загрузки сохранения и переключения на выбранного персонажа через локальный API игры.
- Карта, персонажи и семьи берутся из снимка; фиксированных имён и ID в текущем протоколе нет.
- Экспериментальная передача координат и сообщений в игровой телефон.
- Подтверждение обработки сообщения на стороне получателя.

Серверные тесты, тесты распаковки и сценарий гостя с имитацией API игры проходят. Полный сценарий версии 0.5 между двумя физическими ПК ещё требует проверки. Передача сетевого текста в телефон первого ПК была подтверждена в раннем прототипе.

**Пока не синхронизируются:** действия, анимации, время, предметы, деньги, отношения и остальное состояние мира. Координаты применяются дискретным переносом персонажа. Совместимость с произвольными сторонними модами и автоматическая сверка зависимостей ещё не обеспечены.

## Требования

- Windows, inZOI и одинаковая версия игры на обоих ПК.
- Установленный и включённый мод на каждом ПК.
- Доступный локальный MCP API игры на `127.0.0.1:11212`.
- Node.js 22+ для запуска из исходников; подготовленный комплект включает отдельный runtime.
- Windows PowerShell 5.1 для помощника.
- inZOI ModKit для редактирования и сборки мода.

Обычная домашняя LAN подходит для проверки. Адреса адаптеров Radmin VPN и Hamachi также показываются в комнате; мод не устанавливает и не настраивает эти приложения.

## Запуск подготовленного комплекта

1. Содержимое папки `mod` поместить в `Документы\inZOI\Mods\InGame` на обоих ПК.
2. Папку `helper` сохранить целиком и запустить `start-helper.cmd` на каждом ПК.
3. Хост сохраняет текущую игру и выходит в главное меню. Через **F2 → Хост: выбрать сохранение** выбирает файл и создаёт комнату.
4. Гость из главного меню открывает F2, выбирает «Гость», вводит адрес и код хоста.
5. Гость выбирает персонажа другой семьи и нажимает **«Скачать сохранение и войти гостем»**. После загрузки снова открывает F2 для завершения входа.

Сохранения гостя не перезаписываются. Повторный вход устанавливает новую копию; старые копии автоматически не удаляются. Передаётся выбранный сохранённый файл, а не несохранённое состояние. Steam Cloud продолжает работать штатно; помощник им не управляет.

Подробности: [инструкция версии 0.5](together/SESSION-0.5.md).

## Структура исходников

| Путь | Назначение |
| --- | --- |
| `together/ui/` | Интерфейс комнаты и ввода сообщений |
| `together/lua/` | Мост между UI, представлением B1 и симуляцией B2 |
| `together/server.cjs` | Сетевой сервер комнаты, снимки, координаты и подтверждения |
| `together/companion.cjs` | Локальный помощник установки и загрузки сохранения |
| `together/session.ps1` | Сценарии создания комнаты и входа гостя |
| `together/prepare-save.ps1` | Подготовка архива выбранного сохранения |
| `together/install-save.ps1` | Проверка и установка архива в отдельную папку |
| `together/import-modkit.ps1` | Импорт UI в открытый ModKit через MCP |
| `together/*test*` | Автоматические проверки |

## Разработка и сборка

Репозиторий содержит исходники прототипа. Рабочий Unreal-проект ModKit и сгенерированные защищённые пакеты сюда не входят.

Текущий технический ID мода — `InZOITogether_CFE6AC67`, имя UI-приложения — `together_chat`. При переносе в другой проект ModKit нужно согласованно заменить ID в UI, Lua, помощнике и скриптах импорта.

Открыть проект в ModKit и включить его локальный MCP (`127.0.0.1:11213`). Из корня репозитория импортировать UI:

```powershell
.\together\import-modkit.ps1
```

Lua-файлы импортируются в рабочую область ModKit со следующими путями:

| Исходник | Путь в `workspace/lua` |
| --- | --- |
| `lua/PhoneClient.lua` | `B1/Zoi/PhoneBridge.lua` |
| `lua/PhoneReceiver.lua` | `B2/Zoi/PhoneProbe.lua` |
| `lua/ClientMain.lua` | `B1/Main.lua` |
| `lua/Main.lua` | `B2/Main.lua` |

Для B1 и B2 нужны привязки `type: Zoi`, `key: *` к соответствующим модулям. Проверить UI и Lua средствами ModKit и выполнить штатную упаковку. Защищённые файлы готового пакета вручную не изменять.

Для запуска локального помощника из исходников:

```powershell
node .\together\companion.cjs
```

Помощник слушает только `127.0.0.1:11215`. Сервер комнаты использует порт `11214`. Игровой MCP гостю по сети не передаётся: помощник каждого ПК обращается к собственной игре.

## Проверки

Из корня репозитория на Windows:

```powershell
node --test together/server.test.cjs together/session.test.cjs
powershell.exe -NoProfile -ExecutionPolicy Bypass -File together/test-save-install.ps1
```

Проверяются права на координаты и семьи, доставка и подтверждение сообщений, скачивание снимка, отдельная установка, контрольная сумма и защита от выхода путей ZIP за целевой каталог. Проверки установки создают тестовые данные; тест сценария гостя использует имитацию API и не загружает реальную игру.
