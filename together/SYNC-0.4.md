# Проверка 0.4 на двух ПК

> Архивная инструкция версии 0.4. Актуальный запуск описан в [SESSION-0.5.md](SESSION-0.5.md).

Установить `inZOI-Together-0.4-sync.zip` на втором ПК при закрытой игре: папка `InZOITogether_CFE6AC67` должна находиться в `Документы/inZOI/Mods/InGame`. Первый ПК использует активный предпросмотр ModKit той же версии.

Загрузить копии стартового сохранения RedCity: первый ПК — Тиана Кокс (24534), второй — Алисия Кемп (24676). Подключиться через F2 разными игроками к серверу первого ПК. Код комнаты прежний; адрес второго ПК нужно брать из текущей LAN первого ПК.

Для телефона отправить новый уникальный текст с ПК1 и открыть у Алисии переписку с Тианой. Статус «Телефон второго ПК подтвердил обработку сообщения» означает подтверждение Lua адресата. Визуальную запись проверить отдельно. Если подтверждения нет, сохранить снимок F2 со строкой состояния телефона.

Для координат включить кнопку синхронизации на обоих ПК. Снять игровую паузу, пройти своим персонажем несколько шагов и проверить его копию на другом ПК. Обновление выполняется дискретным переносом через movement.teleport; интерполяция, анимации, отмена автономных действий NPC, взаимодействия и время мира не синхронизируются. Локальный персонаж не переносится входящими координатами. Сервер ограничивает ID персонажа выбранным местом, карту и диапазон координат, отбрасывает координаты старше 3 секунд. Lua обновляет положение примерно раз в 2 секунды игрового времени.

Проверено разработчиком: три интеграционных теста сервера, анализ UI и Lua без ошибок; живое обновление координат Тианы через B2 → B1 → cfg. Реальное движение между двумя ПК и получение телефона на втором ПК ещё требуют проверки пользователем.
