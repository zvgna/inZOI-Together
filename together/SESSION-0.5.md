# Комната Хост / Гость — 0.5

Это промежуточный этап разработки кооператива: автоматический перенос стартовой копии, динамические персонажи и карта, экспериментальные координаты и телефон. Общие действия, время, деньги, предметы и состояние мира пока не синхронизируются.

## Установка

В архиве две папки. Содержимое `mod` скопировать в `Документы/inZOI/Mods/InGame`. `helper` хранить целиком в удобном месте, например на рабочем столе. На каждом ПК один раз запустить `helper/start-helper.cmd`; окно помощника оставить открытым. В комплект включён Node.js, отдельно ставить его не нужно. Игра должна предоставлять локальный MCP API (порт 11212), мод должен быть включён. Помощник доступен только на 127.0.0.1:11215 и использует случайный ключ, передаваемый в конфигурацию мода.

## Хост

Сохранить текущую игру обычным способом и выйти в главное меню. Открыть F2, выбрать «Хост», нажать «Хост: выбрать сохранение». Выбрать сохранение из списка и нажать «Загрузить сохранение и создать комнату». Помощник загрузит выбранный файл, соберёт список живых персонажей жилых семей и создаст неизменяемый снимок. После загрузки снова открыть F2: адрес, новый код и роль будут подставлены автоматически. Код комнаты также выводится помощником. Адрес для гостя взять из блока Wi-Fi/LAN.

Хост хранит свою обычную локальную игру. Steam Cloud работает штатно; помощник не управляет им и не проверяет завершение облачной синхронизации. Гость получает копию выбранного сохранённого файла, а не текущее несохранённое состояние.

## Гость

Находясь в главном меню, открыть F2, выбрать «Гость», ввести адрес хоста и код, подключиться. Выбрать персонажа другой семьи и нажать «Скачать сохранение и войти гостем». Помощник скачает архив, проверит хеш, установит его в новую папку SaveGames, запросит загрузку и переключит управление на выбранного персонажа. После загрузки открыть F2 — сетевой вход завершится автоматически. Старые сохранения гостя не перезаписываются. При повторном входе устанавливается новая копия; старые копии автоматически не удаляются.

## Текущее ограничение проверки

Прошли тесты сервера и распаковки, анализ UI/Lua. Полный запуск этого потока на двух ПК ещё не подтверждён. Нельзя заранее гарантировать любые модифицированные сохранения: автоматическая сверка полного набора сторонних модов и версии игры ещё не реализована. Сохранения без двух жилых семей отклоняются. Игра сама может отклонить несовместимый файл при загрузке; помощник прекращает ожидание по тайм-ауту, не запускает повторную загрузку.

Первый тест: обычное сохранение без дополнительных модов, одинаковая версия игры на обоих ПК. Сначала проверить автоматическую установку и выбранного персонажа, затем сообщение ПК1 → ПК2, затем несколько шагов с проверкой координат. При паузе Lua-координаты перестают обновляться; снимки старше трёх секунд не применяются.
