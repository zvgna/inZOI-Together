# Проверка из разных городов

Для первого теста используйте Radmin VPN на обоих ПК. Hamachi также можно использовать как транспорт: в моде указывается его адрес хоста. Подключение через эти программы ещё предстоит проверить с двумя играми.

## Подготовка сети

1. Установите Radmin VPN с [официального сайта](https://www.radmin-vpn.com/).
2. Хост создаёт новую сеть с названием и паролем; гость присоединяется к ней. Оба компьютера должны отображаться в одной сети. Подробности — в [официальной справке](https://www.radmin-vpn.com/help/).
3. Запустите одинаковую сборку мода и помощник на обоих компьютерах.
4. Хост создаёт комнату мода и выбирает в ней адрес **Radmin**. Передаёт гостю этот адрес и код комнаты. Название и пароль сети Radmin — отдельные данные, их вводят только в Radmin VPN.
5. Гость вводит `http://<VPN-IP-хоста>:11214` и нажимает **«Проверить связь с хостом»**. Мод проверяет версию протокола и показывает время ответа сервера.

Не используйте на гостевом компьютере `127.0.0.1` или домашний Wi-Fi-адрес хоста. Проброс портов на роутере для этого сценария не требуется. Помощник и API игры остаются локальными; по VPN используется только сервер комнаты на TCP 11214.

## Если сервер недоступен

Проверьте, что создана именно комната мода, оба ПК находятся в одной сети VPN, адрес скопирован без ошибок и сервер разрешён брандмауэром. При конфликте маршрутов отключите другие VPN на время проверки.

Для адресного разрешения можно на ПК хоста запустить PowerShell от администратора и выполнить в папке помощника:

```powershell
.\allow-peer.ps1 -PeerAddress '<VPN-IP-гостя>'
```

Скрипт разрешает только TCP 11214 для указанного гостя на адаптере VPN. При нескольких адаптерах добавьте `-InterfaceAlias '<имя адаптера>'`. Брандмауэр отключать не нужно.

## Порядок проверки мода

1. Связь с сервером и вход в одну комнату.
2. Скачивание сохранения, загрузка и выбор разных семей.
3. Сообщение из телефона хоста в телефон гостя и ответ обратно.
4. Несколько шагов рядом с проверкой положения на обоих ПК.
5. Дружелюбное приветствие. Персонажи должны быть свободны от текущих занятий.
6. Рукопожатие и объятие, если игра разрешает их для выбранной пары.

Взаимодействия — экспериментальный этап: хост проверяет доступность и запускает действие, затем команда передаётся гостю. Во время запроса перемещение копий по сетевым координатам приостанавливается. Независимые симуляции могут расходиться; синхронность анимаций, отношений и других результатов пока не гарантируется.

При ошибке приложите снимки F2 с обоих ПК, версии игры и мода и время ответа сервера. Пароли VPN, коды комнаты и личные сохранения публиковать не нужно.
