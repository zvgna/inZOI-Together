# Запуск из одной папки

Для локальной проверки помощник установлен внутрь `Документы\inZOI\Mods\InGame\InZOITogether_CFE6AC67\helper`. В корне папки мода находится `Play-Together.vbs`.

Запускайте `Play-Together.vbs` двойным щелчком. Он открывает inZOI через Steam, если игра ещё не работает, и запускает помощник без консоли. После закрытия отслеживаемого процесса игры запускатор завершает принадлежащие ему помощник и сервер комнаты. Если игра уже открыта, запускатор присоединяется к ней.

Автозапуск при обычном запуске inZOI из библиотеки Steam пока отсутствует. Не добавляются задания планировщика, службы и записи автозагрузки Windows. Старое окно `start-helper.cmd` нужно закрыть перед запуском нового режима.

Файлы текущей тестовой установки:

```
InZOITogether_CFE6AC67/
  mod_manifest.json
  Play-Together.vbs
  ui/
  lua/
  helper/
    node.exe
    Node-LICENSE.txt
    launch.ps1
    companion.cjs
    server.cjs
    ...
```

Для создания комнаты выберите сохранение через F2 в игре и нажмите «Загрузить сохранение и создать комнату». После сообщения «Выбор запомнен» сохраните текущую игру и выйдите в главное меню. Помощник дождётся меню и продолжит загрузку сам; открывать F2 в меню не требуется. Ожидание ограничено 15 минутами. Запускатор не заменяет и не сохраняет текущую игру автоматически.

Архив 0.8.1 не пересобран: этот режим пока проверяется непосредственно на первом ПК. Второму ПК потребуются эти же дополнительные файлы внутри папки мода.
