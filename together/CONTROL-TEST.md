# Проверка управления в игре хоста · 0.8.1

В 0.8.1 выбор сохранения сделан кнопками, уменьшен нижний отступ и добавлен поиск комнаты через «Гость» или «Найти хоста в Radmin / LAN». Для поиска хост уже должен создать комнату, а оба помощника должны быть запущены. Адрес подставляется автоматически, код комнаты вводится отдельно. Поиск использует UDP 11216, соединение — TCP 11214. Если VPN не передаёт широковещательные запросы или брандмауэр блокирует их, используйте адрес хоста вручную. Поиск ещё не проверен на двух ПК через Radmin.

Это экспериментальный комплект для отдельной тестовой копии сохранения. Он добавляет выполнение выбранных действий на компьютере хоста. Полноценного кооператива в этой версии ещё нет: штатные клики, перемещение, учёба, навыки и состояние мира гостя пока не синхронизируются.

1. Остановите прежние помощник и сервер. Установите этот комплект целиком на оба ПК по инструкции README.
2. Запустите помощник на обоих ПК. Создайте комнату хостом, скачайте и загрузите её сохранение гостем. Подключитесь через F2 и выберите разных персонажей.
3. На хосте используйте адрес `http://127.0.0.1:11214`. Гость использует адрес хоста из Wi-Fi, Radmin или Hamachi.
4. Завершите текущие действия обоих персонажей. На хосте нажмите **«Передать персонажа гостю»** в новом блоке F2.
5. Нажмите **«Получить действия с другим игроком»**, выберите доступное действие и **«Выполнить у хоста»**. Запрос запускается в игре хоста; игра гостя пока не повторяет его.
6. Попробуйте отправить встречное действие с другого ПК. Пока первое занимает пару, второй запрос должен получить ответ о занятости.
7. Перед выходом или сменой сохранения нажмите на хосте **«Вернуть управление ИИ»**. Только затем закрывайте помощник.

Если список действий пуст, игра не предоставила доступных взаимодействий для этой пары. Проверьте, что персонажи находятся рядом и свободны. В этой версии мод сам их не сближает.

После выполнения сохраните игру штатной кнопкой хоста. Сохранение результата взаимодействия после повторной загрузки ещё нужно проверить; мод не выполняет принудительное сохранение.

При неизвестном результате повторный запуск отключён. При аварийном закрытии помощника Lua возвращает исходную настройку после отсутствия новых запросов; пауза задерживает обработку. Если помощник сообщает о незавершённом журнале, оставьте игру без паузы на обычной скорости и повторите подключение. Не удаляйте журнал для обхода блокировки.
